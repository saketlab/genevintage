# GSE52529: historical single-cell reference regression

The file gse52529_gencode_v17.txt.gz contains every row ID from:
https://ftp.ncbi.nlm.nih.gov/geo/series/GSE52nnn/GSE52529/suppl/GSE52529_fpkm_matrix.txt.gz

GEO public date: 2014-03-23. The matrix contains 47,192 genes x 372 cells (FPKM).
Downloaded 2026-09-12; source gzip MD5: 43db65c905df478f18c996264472563d.
GSM1268960 documents GENCODE 17 on hg19:
https://www.ncbi.nlm.nih.gov/geo/query/acc.cgi?acc=GSM1268960

All IDs including version suffixes match the release-17 GTF exactly.
The old index started at GENCODE 20 and selected GENCODE 25 / GRCh38.
Adding primary-assembly GENCODE 17-19 fingerprints selects release 17 / GRCh37
using the unchanged score. Generated from the complete archived gene records
using fingerprint() in data-raw/utils.R, with assembly 37 and no frozen release.
The data-raw/build_gencode.R job range now includes these historical releases.
